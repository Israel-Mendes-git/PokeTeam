# PokeTeam

App Android para montar times Pokémon rápido, sozinho ou com amigos.

**[Baixar o APK](https://github.com/Israel-Mendes-git/PokeTeam/releases/latest)**: o app avisa quando sai versão nova.

- **Pokédex** offline com busca e fraquezas
- **Montar time** com análise dos pontos fracos e sugestões de quem completa
- **Sortear** time ou vagas
- **Draft** entre 2 a 4 amigos no mesmo celular
- **Pools** para limitar os pokémons da sessão, inclusive pelo elenco de modpacks de Cobblemon
- **12 temas** em pixel art

Para compilar e manter o projeto, veja [DESENVOLVIMENTO.md](DESENVOLVIMENTO.md).

---

Projeto de fã, sem relação com Nintendo, Game Freak ou The Pokémon Company. Dados e sprites: [PokéAPI](https://pokeapi.co). Fonte: [Pixelify Sans](https://github.com/eifetx/Pixelify-Sans) (OFL).
